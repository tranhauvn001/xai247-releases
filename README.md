## Kiểm tra file tải về

- Windows (PowerShell): `Get-FileHash .\<tên-file>` · Linux: `sha256sum <tên-file>` · macOS: `shasum -a 256 <tên-file>` — kết quả phải trùng cột SHA-256.
- Bộ cài Windows chưa ký số: lần đầu cài, SmartScreen có thể cảnh báo → **More info → Run anyway**.
