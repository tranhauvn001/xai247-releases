# XAI247 Releases

Nơi phát hành file cài đặt các ứng dụng XAI247: extension VS Code, XAI247 Desktop, CLI `xai247`, XAI247 Switch.

- File cài nằm ở mục **[Releases](../../releases)**, không nằm trong mã nguồn của repo này.
- Mỗi phiên bản là một release, tag theo sản phẩm: `ext-<phiên bản>`, `dsh-<phiên bản>`, `cli-<phiên bản>`, `switch-<phiên bản>`.
- Khách nên tải qua trang của XAI247 (https://xai247.xyz) — trang đó chọn đúng bản mới nhất cho máy của bạn và kèm mã SHA-256 để kiểm tra file.

Repo này chỉ chứa file phát hành; mã nguồn không công khai ở đây.
